## 1. Frontend & UI/UX Development

Speed of interface development is paramount in hackathons. These libraries allow you to assemble professional interfaces in minutes:

| Tool | Category | Why It Matters | Best For |
|---|---|---|---|
| **[Tailwind CSS](https://tailwindcss.com)** | Styling | Utility-first styling without leaving markup | Rapid custom layouts |
| **[shadcn/ui](https://ui.shadcn.com)** | Component Library | Copy-paste clean, accessible React components built on Radix UI | Production-grade UI in seconds |
| **[Lucide Icons](https://lucide.dev)** | Iconography | High-quality open-source SVG icons with zero setup | Visual indicators & buttons |
| **[v0.dev](https://v0.dev)** | Generative UI | Prompts directly generate React + Tailwind component code | Instant page mockups |
| **[Figma](https://figma.com)** | Design & Prototyping | Industry standard vector UI wireframing | Quick team alignment & pitch graphics |

## 4. Hosting & Cloud Deployment

Never demo on `localhost:3000` when free cloud deployments take under 3 minutes:

- **[Vercel](https://vercel.com):** One-click Git deployment for Next.js, React, and serverless edge functions. Free SSL and custom preview domains.
- **[Render](https://render.com):** Free tier hosting for Python FastAPI, Docker containers, and background worker jobs.
- **[Modal](https://modal.com):** Run serverless Python code and GPU compute with pay-per-second billing and generous starter credits.
- **[Railway](https://railway.app):** Instant microservice orchestration and containerized database spins.
