# Health & Wellness

[← Back to Idea Index](00-IDEA-INDEX.md) · [← Fintech](03-fintech.md)

> **Note:** These are non-clinical, administrative/wellness-support ideas : none involve diagnosis or treatment decisions. Keep any hackathon health project clearly scoped away from clinical advice.

| Idea | Problem | MVP Demo | Advanced Scope | Anti-pattern |
|---|---|---|---|---|
| **Medication Schedule Simplifier for Multiple Prescriptions** | People managing several medications (common for elderly patients or chronic conditions) struggle to track complex timing rules (with food, spacing between doses, etc.) : a purely logistical problem, not a clinical one. | Input a list of medications with their timing rules → generate an optimized daily schedule → simple reminder UI, clearly labeled as an organizational tool, not medical guidance. | | Cut: interaction/dosage checking (clinical territory : avoid). Add if time allows: a caregiver view for someone managing another person's schedule. |
| **Symptom Pattern Journal (Non-Diagnostic)** | People with recurring symptoms (headaches, fatigue, flare-ups) often can't identify their own triggers because tracking by memory is unreliable. | Daily log of symptoms + potential factors (sleep, food, stress, weather) → correlate patterns over time → present as "things worth discussing with your doctor," never as a diagnosis. | | Cut: any diagnostic language or suggestions. Add if time allows: exportable summary formatted for a doctor's visit. |
| **Workout Consistency Coach (Behavioral, Not Prescriptive)** | Most fitness apps focus on workout plans, but the actual failure point for most people is consistency, not knowing what exercises to do. | Track workout completion (not performance) → detect patterns in what causes skipped sessions (day of week, time, weather) → give specific, personalized nudges based on the user's own drop-off pattern. | | Cut: exercise-form checking (needs computer vision, high effort). Add if time allows: a streak-recovery mechanic that reduces all-or-nothing quitting. |
| **Caregiver Coordination Board** | Families coordinating care for an aging or ill relative across multiple people (siblings, professional caregivers) lose track of who did what, leading to gaps or duplicated effort. | Shared task/log board scoped to one care recipient → log care activities (meds given, appointments, notes) → visible to all caregivers with a simple "who did what, when" timeline. | | Cut: EHR/clinical system integration. Add if time allows: an "unstaffed gap" alert when no caregiver is scheduled for an upcoming period. |
| **Mental Load Tracker for Household Mental Health** | The invisible cognitive labor of running a household (remembering appointments, anticipating needs, planning ahead) is unevenly distributed and rarely made visible, contributing to burnout. | Log not just tasks done but *mental tasks* (remembering, planning, anticipating) per household member → visualize the imbalance over time, not just physical task counts. | | Cut: prescriptive "fixes." Add if time allows: a weekly reflection prompt that surfaces the biggest imbalance. |
