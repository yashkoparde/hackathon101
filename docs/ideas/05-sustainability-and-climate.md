# Sustainability & Climate

[← Back to Idea Index](00-IDEA-INDEX.md) · [← Health & Wellness](04-health-and-wellness.md)

| Idea | Problem | MVP Demo | Advanced Scope | Anti-pattern |
|---|---|---|---|---|
| **Household Energy Anomaly Detector** | Most people have no idea when their energy usage spikes or why : utility bills arrive a month too late to act on. | Input historical usage (utility CSV export or synthetic data) → detect anomalies against the household's own baseline → suggest likely causes based on the pattern (time of day, seasonality). | | Cut: smart meter live integration. Add if time allows: appliance-level breakdown estimation from usage shape. |
| **Local Repair & Reuse Directory** | People default to throwing away broken items because finding a local repair option takes more effort than buying new. | Directory of local repair services/makerspaces by item category → simple search/filter by what's broken → include a rough cost/environmental-impact comparison versus buying new. | | Cut: real-time inventory/availability. Add if time allows: community-submitted repair success stories. |
| **Food Waste Reduction Planner** | Households routinely buy food that spoils before it's used, and there's no simple feedback loop connecting purchases to what actually gets wasted. | Log groceries with purchase date → track what's used vs. discarded → surface a simple pattern ("you waste greens most often : buy less next time, or plan a recipe by day 4"). | | Cut: barcode scanning (nice-to-have, not core). Add if time allows: recipe suggestions using soon-to-expire items. |
| **Carbon Impact Comparison for Everyday Decisions** | People want to make lower-impact choices but lack quick, comparable numbers at the moment of decision (this flight vs. that one, this product vs. that one). | Pick one narrow decision category (e.g., commute options, or two product categories) → use published emission-factor data to compute comparable estimates → present as a simple side-by-side, not a dashboard. | | Cut: broad multi-category tracking. Add if time allows: a personalized "impact saved this month" running total. |
| **Community Resource-Sharing Board** | Neighbors often own duplicate rarely-used items (tools, equipment) that could be shared instead of everyone buying their own : but there's no low-friction way to coordinate this locally. | Simple listing board scoped to a neighborhood/community group → post items available to borrow → basic request/coordinate flow. | | Cut: payment/deposit handling. Add if time allows: a trust/reputation signal based on return history. |
