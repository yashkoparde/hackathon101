# Education

[← Back to Idea Index](00-IDEA-INDEX.md) · [← Sustainability & Climate](05-sustainability-and-climate.md)

| Idea | Problem | MVP Demo | Advanced Scope | Anti-pattern |
|---|---|---|---|---|
| **Concept Gap Finder for Self-Learners** | Self-directed learners (via YouTube, docs, courses) often build on shaky foundations without realizing it : they don't know what they don't know until it bites them later. | User states a topic they're learning → generate a short set of foundational-concept probe questions → identify likely gaps based on wrong/uncertain answers → recommend what to review first, prioritized. | | Cut: full curriculum generation. Add if time allows: a visual "concept map" showing dependencies between topics. |
| **Peer Explanation Matcher** | The best way to solidify understanding is often explaining a concept to someone else : but students rarely have a structured way to find a peer who's ready to trade explanations. | Users submit what they're confident explaining and what they want explained → match pairs where each person can help the other → simple structured explanation prompts to keep sessions focused. | | Cut: real-time video/chat infra (use async text exchange for the demo). Add if time allows: a rating system so good explainers surface faster in future matches. |
| **Study Session Effort Estimator** | Students consistently misjudge how long assignments/studying will actually take, leading to last-minute cramming or procrastination born from an inaccurate mental model of the workload. | User estimates time for a task → logs actual time taken → over several tasks, the tool learns the user's personal estimation bias (e.g., "you tend to underestimate by 40%") and adjusts future estimates automatically. | | Cut: calendar integration. Add if time allows: breaking large tasks into sub-estimates for better accuracy. |
| **Skill-to-Job Gap Mapper** | Students and career-changers often don't know exactly which skills separate them from a specific target job : generic "learn to code" advice isn't actionable. | User inputs current skills + a target job/role → compare against typical requirements for that role → output a prioritized gap list, not just a generic skill checklist. | | Cut: live job-posting scraping (use a curated reference dataset instead). Add if time allows: linking each gap to a specific free learning resource. |
| **Classroom Participation Equity Tracker** | Teachers often unconsciously call on the same few students repeatedly, while quieter students go unnoticed : a hard pattern to self-monitor while actively teaching. | Simple in-class logging (tap a student's name when they participate) → visualize participation distribution over a session/term → flag students who haven't been called on recently. | | Cut: automatic voice-detection participation logging (high effort, error-prone). Add if time allows: anonymized comparison across multiple class sessions. |
